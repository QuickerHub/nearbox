# 0001 数据和连接都只在本机与局域网，不经过任何云端

- 状态：已采纳
- 日期：2026-09-06
- 相关：`src/main/lan-server.ts`、`src/main/network.ts`；README「它解决什么」「数据在哪」

## 背景

手机和电脑之间要传任务、图片、Agent 的实时输出。走云端中转最省事，但意味着要有账号、有服务器、
有别人的机器看得到你的代码目录和对话。Nearbox 的用户是一个人和自己的几台设备，通常在同一个 Wi-Fi 下。

## 决定

不做任何服务端。电脑起一个 HTTP / WebSocket 服务，只接受回环地址和私有网段（10/8、172.16/12、192.168/16）的连接，
其余一律 403「仅允许局域网访问」。手机靠 UDP 广播、二维码或六位验证码找到并配对电脑；配对令牌只存在双方本地。
全部数据放在 `%APPDATA%\Nearbox\nearbox\` 下。

## 后果

- 不在同一个局域网就用不了。这是刻意的：不做外网穿透，不做中继，不做账号。
- 「局域网」的判断是按 IP 网段做的；VPN、虚拟网卡会被排到后面（`network.ts` 里的适配器排序）。
- 任何「同步到另一台电脑」「离家也能看」的需求都撞这条线，要先改 `docs/scope.md`。
